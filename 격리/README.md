# 격리 — 원전이 아닌 문서 (2026-09-16)

여기 있는 파일은 **삭제하지 않고 격리**한다. 삭제하면 "T(함정)가 어디서 들어왔는가"의
증거가 사라진다. 참조하지 말 것 — 원전은 `HMOS_논문1~5*.md`다.

## 격리 사유

T(함정)는 오종래 원전 이론에 없는 범주다. 이론 5편(논문1~5)에 단 한 번도 나오지 않는다.
(유일한 인접 히트는 논문3 Code18 "허상제거 — 함정·허상(Ghost) 소거"인데, 이는 범주가
아니라 연산자 하나다.)

아래 문서들은 그 T를 K와 나란히 세워 이론인 것처럼 유통시킨 경로다.

**기계 생성물 판정 근거:**
- 작성자가 `Un-named` — Word는 사용자 이름을 남긴다
- 생성 시각과 수정 시각의 차이가 9~10밀리초 — 사람이 쓴 문서에서 나올 수 없는 값
- `docProps/app.xml`에 Application·TotalTime·Company가 전부 없음 — Word의 흔적이 하나도 없다
- "T (함정) = K를 놓쳤을 때 나타나는 오류 패턴"이 에이전트 생성 스펙
  (`QUESTION_TYPE_SPEC.md`, `ENGINE_SPEC.md`, `CLAUDE.md`)과 **글자 단위로 동일**

**대조군:** `HMOS_Dev_Specs_v2-12/서술형채점_12_채점가이드_비개발자용.docx`는
작성자 `Seongchan Ahn`, 작성→수정 35분, **"함정" 0회**다. 사람이 쓴 문서에는 T가 없다.
그래서 이 파일은 격리하지 않았다.

## 원칙

HMOS에 함정은 없다. 학생이 틀린 것은 함정에 빠진 것이 아니라 **자기 이해가 아직 안 선 것**,
즉 실체가 아직 접혀 있는 것이다. 질문은 실체를 묻고, 학생은 접힌 것을 펴고, 선생은 비춘다.
