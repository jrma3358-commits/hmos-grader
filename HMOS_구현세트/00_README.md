# HMOS 루브릭·채점 구현 세트 (클로드 코드용)

## 읽는 순서
1. 01_순서도.md — 부품을 잇는 흐름 (Mermaid). 전체 구조를 먼저 본다.
2. 02_구현명세.md — 각 부품 F1~F6·GJ의 입력·출력·규칙. 봉인①~⑥ 처리 원리.
3. 03_구현지침.md — 간결 요약 지침.
4. 04_기본물음_배치표.docx — 다섯 기본 물음 ↔ 네 파트 ↔ 요소 대응.
5. 05_점검목록.md — 구현 전 확인할 미정 사항(A~F).

## 한 줄 요약
질문 인식(구현됨)이 준 급소 → F2로 파트별 조각 수 셈 →
루브릭·채점기준·부분점수·모범답안 동시 생성 → 학생 답을 GJ로 O/X 채점 → 부분점수+자취.

## 구현 순서 (권장)
F2(조각 역산)부터 → 문항 하나로 검증(손산출 대조) → F1·F3~F6 → GJ → 채점 실행.

## 봉인 경계 (중요)
①~⑥ 규칙의 «처리 구조»는 명세에 있으나 «실제 판정 알맹이»는 봉인 모듈에서 import.
코드는 흐름·호출만 구현하고 규칙을 지어내지 않는다. 지어내면 HMOS가 아니라 흉내다.
