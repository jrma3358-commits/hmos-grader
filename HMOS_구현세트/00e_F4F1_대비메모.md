# F4·F1 구현 대비 메모 (부딪칠 지점 + 미리 정할 것)
_2026-09-28. F2·F3·F5 구현 완료 후, 다음 F4·F1을 만들 때 헤매거나 흉내내지 않도록._

## 근본 원칙 (F4·F1 공통)
두 함수 다 **«급소 인식이 이미 한 일을 받아서 형식에 담는»** 함수다.
- 급소 인식(입구·F2 앞)이 문항의 급소·실체를 이미 뽑았다.
- F1 = 그 실체를 고정 물음 틀에 **그대로 대입**. (새로 뽑지 않음)
- F4 = 그 급소를 조각의 **충족조건으로 명세**. (새로 판단하지 않음)
- 즉 «새로 판단」이 아니라 «받아서 형식화» — 이것이 LLM 흉내를 막는 열쇠.
  F1·F4 안에서 LLM이 실체·조건을 «지어내면» 흉내다. 받아서 담기만 한다.

---

## F4 (충족조건명세 · 봉인⑥) — 부딪칠 지점 3

### ① 충족조건 = 판정 기준(구조) + 자취용 설명(자연어), 역할 분리
- 판정 기준은 **「급소 도달 여부」**(GJ가 대조 가능한 구조).
- 자연어는 그 **설명**(자취용). 「근과 계수 관계를 옳게 나타냄」 등.
- → 충족조건 객체 = { 판정기준: (급소 실체 도달 조건, 구조), 설명: (자연어) }.
- 자연어만 두면 코드가 O/X 판정을 못 한다. 판정 가능한 구조가 반드시 있어야.

### ② O/X 경계 판정은 GJ, F4는 조건 정의만 — 분담
- F4 = 「이 조각의 충족조건이 무엇인가」만 명세.
- 실제 O/X 판정(닫힌정답=완전일치 / 열린인문=급소도달)은 **GJ가 대조**.
- 둘을 나누면 안 겹친다: F4=조건 정의, GJ=조건 대조.

### ③ 수행 파트(③풀기)의 충족조건은 형식이 다름
- 요소 파트(①②④): 충족조건 = 「이 급소 실체에 닿았나」.
- 수행 파트 ③풀기(F3에서 null): 충족조건 = 「연산이 정확한가」(정확성).
- **⑤표현 파트는 채점에서 소거함** — 논리성 판정은 AI 재현성 편차가 가장 큰 자리라 뺐다.
  급소에 닿았으면(④) 표현은 부차적. 채점은 ①②③④ 네 파트로.

---

## F1 (파트투영 · 봉인①) — 부딪칠 지점 3

### ① 실체는 급소 인식이 주고, F1은 「받아서 틀에 대입만」
- 급소 인식(F2 앞)이 이미 「이 문항의 실체」를 갖고 있다.
- F1은 그 실체를 고정 물음 틀에 **그대로 꽂는다**. 새로 뽑지 않는다.
  예) 「( )에 대하여 이해했는가」의 ( )에 급소 인식이 준 «근과 계수 관계»를 대입.
- LLM으로 실체를 «다시 뽑거나 재작성」하면 흉내. 받아서 대입만.

### ② 고정 물음 틀의 위치
- 다섯 기본 물음(손그림)을 어디 두고 F1이 불러오나 — 정해야 함.
  ① 개념 이해 / ② 조건·상황 구체화 / ③ 연산·논증 정확 / ④ 급소 값·실체 도달
  (⑤ 표현/논리성은 채점에서 소거 — 네 파트로 운영)
- 틀은 **고정**(하드코딩/설정), AI가 못 바꿈. 이것이 «고정 틀»의 실체.

### ③ 계열별 물음 옷 갈아입기는 조합(입력)에서
- ②세우기: 수리=식 세우기 / 논술=논지 세우기 (계열별).
- 계열 판별은 F1이 새로 하지 않는다 — **입력의 조합에 이미 계열이 있다**(명세: 조합이 입력).
- F1은 조합의 계열을 따라 물음을 꽂기만.

## 미리 정할 것 — 체크리스트 (오종래)
F4:
- [ ] 충족조건 객체 형식: { 판정기준(구조), 설명(자연어) } 로 둘지
- [ ] O/X 판정은 GJ에 맡기고 F4는 조건 정의만 — 확정
- [ ] 수행 파트(③⑤) 충족조건: 정확성·논리성 판정 형식

F1:
- [ ] 실체는 급소 인식 산출을 받아 대입 (새로 안 뽑음) — 확정
- [ ] 다섯 고정 물음 틀의 저장 위치 (하드코딩/설정/봉인)
- [ ] 계열은 입력 조합에서 — F1은 따르기만
