## 0. 절대 원칙

### 0-1. 엔진 우선 (오종래 2026-10-13, 이 문서 전체에 걸림)
- 논제 5색·급소 인식, 제시문 급소 추출, 연결 강약 판정은 **엔진**이 한다. 구간 측정의 O/X도 엔진이 한다.
- Claude는 엔진 결과를 **문장으로** 펴는 자리(조각 모범 문장 · 처방전 구술)에만 쓴다. 판정 자리에 Claude를 넣지 않는다.
- 엔진이 못 잡으면 AI로 채우지 않는다. 엔진(봉인 목록 · 규칙)을 고친다. 봉인 값은 오종래가 정한다.

### 0-2. 대입논술 채점 실체 원칙 (처방전_규칙 10-0, 오종래 2026-10-23 확정)
대입논술 채점 = **네비게이션 경로 구간 속도 측정**.

1. 논제가 제시한 경로 먼저 (제시문 기반)
2. 4구간 입구·출구 설정 (근거대기 · 세우기 · 논리펼치기 · 답표현하기)
3. 각 구간 입구·출구 대조 = 채점
4. 창의성 아님 — 경로 이탈은 감점

```
논제가 제시한 네비게이션 경로
    ↓
근거대기 → 세우기 → 논리펼치기 → 답표현하기
(입구)      (입구)    (입구)        (입구)
   ↓           ↓         ↓             ↓
(출구)      (출구)    (출구)        (출구)

각 구간의 입구·출구 대조 = 구간 속도 측정
```

| 구간 | 보는 것 |
|---|---|
| 근거대기 | 제시문에서 근거를 제대로 가져왔는가 (입구 확인) |
| 세우기 | 논제가 요구하는 방향으로 논지를 세웠는가 (구간 통과) |
| 논리펼치기 | 경로 위에서 논리가 이어졌는가 (구간 속도) |
| 답표현하기 | 출구에 정확히 도달했는가 (출구 확인) |

- 창의성이 아닌 이유: 제시문이 이미 경로를 깔아 놓았다. 학생이 할 일은 그 경로를 얼마나 정확히 따라갔는가.
- 루브릭 순서: 네비게이션 경로 먼저 → 그 다음 4구간 입구·출구. 순서가 바뀌면 채점이 아니라 취향이 된다.

### 0-3. 네비게이션 경로 원칙 (10-0-1, 확정)
- 논제 = 네비게이션 경로의 주인.
- 제시문 = 각 구간에서 필요에 의해 호출하는 재료.
- 경로: 논제 → 4구간 → 구간별 제시문 호출. 제시문이 경로를 결정하지 않는다.

### 0-4. 5색·급소 → 경로 → 4구간 자동 분할 (10-0-2, 확정)
- 논제 표지(조사·어미·어휘) → 5색·급소 인식 → 네비게이션 경로 자동 생성.
- **급소 = 목적지.** 경로는 자동으로 그려진다.
- 경로 위에 4구간 자동 분할 → 루브릭 완성. 이것이 로직1(인식) → 로직2(채점) 연결의 실체.

## 2. 근거대기 구간 — 공통 규칙 (봉인② 인문, 확정)

- 근거대기 구간 = **논제 개념·조건 노드 + 논제가 부른 제시문 단락마다 하나**.
  - 부른 단락 = 소문항 참조(「[라]~[사]」를 펼친 것) + 소문항 글에 나온 제시문 기호 모두. 없으면 정합 연결 단락.
- 제시문 조각이 있으면 **경로 연결 표지는 조각이 아니다** — 경로 표지로만 남는다 (가):
  연결 C(「바탕으로」 「관점에서」 「활용하여」 …) · 분량·배점 D(「1,001자 이상~1,100자 이하, 배점 60점」) · 지시어(「이」 「그」).
  개념·조건 노드(「포장의 역할」 「30시간 이상」)는 근거로 남는다.
- 기호뿐인 노드(「(나)」 「ⓐ」)는 조각이 아니다 (10-15 안 A).
- 단락 실체 = 그 단락 자체 급소. 두 글자 미만이거나 빈말(「하나」 「것이」)이면 단락 기호 「[나]」 (다).
- **지정 단락 실체 (안 1 확정)**: 지정 연결 단락의 자체 급소가 서지 않으면(MULTIPLE_CONVERGENCE) 실체를 라벨 「[나]」로 둔다. 이 대체는 고치지 않는다 — 틀린 실체보다 라벨이 학생 납득에 덜 해롭다.
- **근거대기 판정 (10-1 확정)**: 실체를 잡았으면 O. 글자 그대로 없어도, 표기 차이(「[사]」 「(사)」)가 있어도 O.

## 3. 유형별 4구간 칸 (봉인② 인문 칸)

유형 판별은 `sealed/f2.ts`가 인식결과로 한다. 위에서부터 먼저 맞는 것.

### 3-1. 선택·적용형 (확정 · 추천안 1~4)
- 판별: 첫 급소가 「관점·입장·이론·시각」과 「중 하나·하나를」을 담고, 그 뒤 연결 C(「관점에서」 「입장에서」 「바탕으로」 「토대로」)와 제시문 기호가 온다. 관점 후보 = 급소 앞 기호(둘 이상) · 적용 대상 = 연결 C 뒤 기호.
- 예: 「[가]와 [나]의 두 관점 중 하나를 선택하고, 그 관점에서 [다]를 해석하시오.」

| 구간 | 조각(역할) |
|---|---|
| 근거대기 | 고른관점 (관점 후보 단락 글) · 대상 (적용 대상 단락) — 고르지 않은 관점은 요약하지 않아도 된다 |
| 세우기 | 관점선택 · 관점요약 |
| 논리펼치기 | 적용해석 ×2 (서로 다른 구절마다) · 관점일관 — 한계 인정 조각은 두지 않는다 |
| 답표현하기 | 목적지 「[다]의 해석」 (핵심어 「해석」) — 급소(「두 관점 중 하나」=선택)가 아니다. 경로 = 관점 후보 단락 → 논제 노드 → 대상 단락 → 목적지 |

### 3-2. 대응형 (확정 2026-10-23 — 대응형 추가 · 배점 원전 그대로 · 대응틀 뺌)
- 판별: 첫 급소에 사례 기호가 둘 이상(원문자 ⓐ~ⓩ · ①~⑳ · ㉠~㉭, 「ⓐ~ⓓ」 범위는 펼침) · 급소 뒤에 「X 중 무엇·어느·어떤」 노드 · 사례 단락 = 급소 앞 기호 · 범주 단락 = 급소와 「X 중」 사이 기호.
- 예: 「(나)의 ⓐ~ⓓ에 담긴 차별적 인식이 (가)의 언어 공동체 구성 요인 중 무엇에 의한 것인지 각각 서술하시오.」 (`검증/인문논술9-1.json`)

| 구간 | 조각(역할) | 엔진이 뽑는 것 |
|---|---|---|
| 근거대기 | 사례 | 사례 단락에서 기호 뒤 표현(나온 곳 가운데 가장 짧은 것 — 「ⓑ쪽발이들한테」 → 쪽발이) · 표현을 풀이한 문장(대화 줄 「이름 :」이 아닌 마지막 문장) |
| 근거대기 | 범주 | 범주 이름 = 「X 중」의 X · 핵심어 = X의 마지막 어절 · 범주 단락에서 핵심어가 든 문장의 「A, B, C 등」 나열 = 후보 |
| 세우기 | 없음 | 대응틀은 대응 조각과 겹친다 (오종래 3) |
| 논리펼치기 | 대응 ×사례 수 | 사례마다 하나. 충족 = 맞는 범주 또는 그 범주로 묶이는 집단 하나만 써도 인정, 다른 사례의 범주가 섞이면 X |
| 답표현하기 | 목적지 | 「ⓐ~ⓓ의 X」 (핵심어 = X의 핵심어). 경로 = 사례 단락 → 급소 → 범주 단락 → 목적지 |

- 배점: §5-2.
- 정답 짝(ⓐ↔연령 …)은 엔진이 정하지 않는다 — **루브릭 조각 `사례.정답`에 직접 넣는다** (오종래 2026-10-23 1, §4-4b). q8 (1)은 원전 채점기준 정답을 넣었다.

### 3-3. 분류형 (확정)
- 판별: 인문 · 급소 둘 이상 · 첫 급소가 「부류」 「묶」을 담는다.
- 예: 「[라]~[사]를 입장이 유사한 두 부류로 묶어 그 중 한 입장을 선택해 요약하고, 이를 바탕으로 다른 입장을 비판하시오.」

| 구간 | 조각(역할) |
|---|---|
| 근거대기 | 참조 단락마다 하나 (§2) |
| 세우기 | 묶음 하나 + 앞 급소마다 선택요약 (선택한 부류 안) |
| 논리펼치기 | 상대 부류 단락마다 상대비판 + 인정재반박 하나. 상대 부류 크기 = 엔진 부류의 작은 쪽 (못 묶으면 참조 단락 수의 절반, 적어도 하나). 모범답안 문단은 조각으로 쓰지 않는다 |
| 답표현하기 | 마지막 급소(목적지) 하나. 경로 = 참조 단락 → 논제 노드(앞 급소 포함, Q · 기호뿐 노드 빼고) → 목적지 |

- **부류는 엔진이 묶는다** (봉인②-부류, `sealed/group.ts`): 대립 축 어휘를 단락 글에서 세어 가 쪽 − 나 쪽 점수의 부호로 가른다. 「A가 아니라 B」는 「아니라」 앞 어휘를 반대쪽으로 센다(밀침). 단락마다 점수가 0이 아니고 두 쪽에 하나 이상씩일 때만 — 아니면 null(조각은 역할로만 서고 부류는 학생 답에서 읽는다). 형태소 분석기 · Claude 없음.
- 대립 축 표 (확정 ①): 「과거 ↔ 현재」 — 과거 중시: 과거 · 옛날 · 옛 · 경전 · 죽은 · 전통 · 역사 · 앞선 / 현재 중시: 현재 · 지금 · 오늘 · 함께 있는 · 지금 여기 (「여기」 → 「지금 여기」).
- 어느 부류를 골랐는지 · 어느 단락이 상대인지는 채점 때 학생 답에서 읽는다.

### 3-4. 그 밖의 인문 논제 (2026-10-14 규칙 + 10-23)
- 근거대기 §2 · 세우기 = 연결 단락의 논제 실체 서술 문장 하나 = 조각 하나 · 답구하기 = 급소 K마다 하나, 경로 흔적 도달.
- 논제 물음이 비판·반박·논박·평가면 논리펼치기에 인정재반박 하나를 더한다.
- 구간 측정은 걸리지 않는다 (§4 is_sectioned 거짓) — G1 조각 판정 · 봉인④-b 게이트 그대로.

## 4. 구간 측정 (`src/rubric/section_check.ts`, 설계 확정 2026-10-23)

### 4-1. 성격
- 글자 대조가 아니다. 문장마다 **부른 단락**(기호 · 그 단락에만 있는 개념) · **축 극성**(대립 축 어휘, 「아니라」 밀침) · **기능표지**(대비 · 결론 · 양보)를 인식해 구간마다 O/X.
- Claude 없음. 낱말 목록은 봉인(§6).
- 적용 대상: `is_sectioned(루브릭)` = 역할 「묶음」 · 「관점선택」 · 「대응」 조각이 있다 → 분류형 · 선택·적용형 · 대응형 (대응형 2026-10-23 추가). 측정 결과에 `유형`이 실린다.
- 러너: 계열 인문사회국어 · is_sectioned면 G1 뒤 측정 결과로 조각 O/X를 덮는다. 봉인④-b 게이트는 걸지 않는다 — 10-2 등급이 대신한다.

### 4-2. 공통 마디
- 문장 나누기: 줄바꿈을 붙이고 「. ? ! 。」 뒤에서.
- 낱말 → 어간: 꼬리(조사·어미) 떼기 → 같은 뜻 대표. 뜻표 = 공통 같은 뜻 + (분류형이면) 그 대립 축의 같은 뜻 (③).
- 단락 개념 = 단락 글의 어간 집합 − 불용어. **고유 개념** = 그 단락에만 있는 개념 — 기호 없이 부른 문장을 알아본다(맞는 단락이 하나일 때만).
- **결론 자리 (나)**: 마지막 결론 표지 문장부터 끝까지, 없으면 마지막 두 문장. 문단으로 가르지 않는다(OCR 쪽 바뀜).
- **닫힘 (다)**: 결론 표지가 있거나 마지막 문장이 판단 서술로 끝남.
- 판정불가(교사 칸)는 단계 판정에서 뺀다.

### 4-3. 분류형 측정
- 범위 표현 「(라)에서 (사)까지」 「[라]~[사]」는 묶음이 아니다 (가).
- 마디: 묶음 문장(기호 셋 이상 또는 둘 + 묶음 표지) → 요약 마디 → 비판 마디(비판 표지부터).
- 학생 묶음: 기호 사이 글이 길면(설명이 끼면) 경계 · 「와/과」는 쉼표가 함께 있을 때 경계.
- 고른 부류: 선택 표지 문장의 기호 → 없으면 비판 마디 첫 문장 기호 나열(뒤가 근거 자리 「의 관점에서」면 고른 부류, 아니면 비판 대상이라 반대쪽).

| 칸 | O 조건 |
|---|---|
| 근거대기 [X] | X만 부른 문장 가운데 하나라도 극성이 X 쪽 · 또는 극성 없이 X 개념을 담는다 |
| 묶음 | 학생 묶음 = 엔진 부류 |
| 선택요약 | 고른 부류 단락이 모두 근거대기 O · 요약 마디 극성이 고른 쪽 |
| 상대비판 (상대 단락 차례) | 비판 마디에서 상대 단락을 부른 문장부터 세 문장 안에 대비 표지 + 근거(고른 부류 기호 · 고른 쪽 극성 · 깎는 평가어 (라)) |
| 인정재반박 | 양보 표지 뒤(같은 문장 또는 다음 두 문장)에 역접 |
| 조건 ① 근거 추출 | 비판 마디의 대비 문장이 모두 제시문 기호 · 개념을 담는다 |
| 조건 ③ 매듭 | 닫힘 |
| 조건 ① 서술 형식 | 묶음 · 요약 · 비판 세 마디 |
| 조건 ③ 결론 | 닫힘 + 상대를 겨눔(상대 기호 · 비판 말 · 깎는 평가어) |

### 4-4. 선택·적용형 측정 (추천안 1~4 · 가~다 확정)
- 고른 관점 = 관점 기호 바로 뒤 **고르기 자리** (「(가)를 통해 해석」 「[나]의 관점에서」).
- 관점 개념어 = 고른 관점 단락에 가장 많이 나오는 비평 관점 묶음 + 그 단락 고유 개념.
- 대상 구절 = 따옴표 인용 · 대상 글과 겹치는 2어절 · 대상에만 있는 낱말(시어). 대상 줄(시는 행, 산문은 문장) 번호로 센다.

| 칸 | O 조건 |
|---|---|
| 고른관점 | 고른 관점을 부르며 그 관점 개념어를 둘 이상 담은 문장 |
| 대상 | 대상 구절을 한 곳 이상 가져옴 |
| 관점선택 | 고르기 자리가 있다 |
| 관점요약 | 관점 선택 문장 둘레(앞 전부 + 뒤 두 문장)에 고른 관점을 부르고(「이는」 지시어 이어받기 인정) 개념어 + 요약·판단 서술 |
| 적용해석 ×2 | 서로 다른 구절마다 — 구절 + (같은·다음 문장에) 개념어 + 해석 서술 |
| 관점일관 | 내재 관점을 고른 답이 해석 근거로 **명시적 외재 표현**(작가 생애 · 시대 사건 · 창작 배경)을 쓸 때만 엔진 X. 물리치려고 부른 문장(부정 · 경계 · 대비)은 근거가 아니다. 그 밖(외재 관점을 고른 답 포함)은 **교사 판정**(판정불가) |
| 조건 ① 근거 추출 | 대상 구절을 관점으로 푼 해석 한 곳 이상 |
| 조건 ③ 매듭 | 닫힘 |
| 조건 ① 서술 형식 | 선택 · 요약 · 해석 세 마디 |
| 조건 ③ 결론 | 닫힘 + 대상 부름 + 관점 부름 + 결론 자리에 해석 결과 문장(방법론 · 일반론이 아니고 대상을 부르며 해석 서술) |

### 4-4b. 대응형 측정 (오종래 2026-10-23 — 1 정답 짝은 루브릭에 직접 · 2 논리펼치기 조건 뺌 · 3 보류)
- **정답 짝은 루브릭 조각에 직접 넣는다** — 대응 조각(과 사례 조각)의 `사례.정답 {범주, 집단[]}`. 엔진은 정하지 않고 읽기만 한다. 없으면 그 대응 칸은 판정불가(교사).
- **구역 자르기**: 사례를 부른 자리 = 기호(ⓐ) · 로마자 기호(「a는」 「(a)」, ⓐ~ⓩ만) · 표현(「틀딱」). 기호와 표현이 괄호 · 따옴표만 사이에 두고 붙으면(「ⓐ틀딱」 「틀딱(a)」) 한 번. 한 사례의 구역 = 그 사례를 부른 자리부터 다음 사례를 부른 자리 앞까지 · 같은 사례를 여러 번 부르면 구역을 합친다.
- **보류 (3)**: 「모두」 총괄 문장 빼기 · 나열 묶음 끝 맞춤은 넣지 않았다 — 나열(「쪽발이와 흑형은 각각 … 거주 지역, 민족, 인종」)의 범주는 마지막 사례 구역에 모두 들어간다.

| 칸 | O 조건 |
|---|---|
| 근거대기 사례 | 모든 사례를 불렀다 |
| 근거대기 범주 | 답에 범주 후보 낱말이 하나 이상 (띄어쓰기 무시) |
| 대응 (사례마다) | 구역에 정답 범주 또는 정답 집단 · 다른 범주 후보가 섞이면 X · 사례를 부르지 않으면 X(미작성) |
| 조건 ① 근거 추출 · ③ 매듭 | 없음 (판정불가 「대응형 — 논리펼치기 조건 없음」) — 4축 논리 펼치기는 대응 조각 판정만 (`/api/axis-grade` 유형 대응형) |
| 조건 ① 서술 형식 | 사례마다 내용 있는 구역(문장 부호 · 머리 조사를 떼고 두 글자 이상) — 「각각」 |
| 조건 ③ 결론 | 사례 구역마다 범주 후보 또는 정답 집단이 있다 (맞고 틀림은 대응 칸이 본다) |

- 단계: 세우기 조각이 없어 **근거대기 · 논리펼치기 · 답표현하기 세 단계**로 어긋남을 센다 (논리펼치기 = 대응 칸만).

## 7. 4축 (`/api/axis-grade`)과 4역량

### 7-1. 4축 모음 (2026-10-21 확정 — 4축도 엔진 판단, Claude 개입 없음 · 10-23 구간 측정 연결)
- 인문 4축: 1 근거대기 · 2 세우기 · 3 논리 펼치기 · 4 답표현하기. 파트 → 축 자동 매핑.
- 축 O = 그 축 조각이 모두 O · 하나라도 X면 X · 판정불가가 있으면 판정불가. 점수 = O 조각 득점 합.
- 논리 펼치기 조건: ① 근거 추출(구간 측정) · ② 기능표지(엔진 논리표지) · ③ 매듭(구간 측정).
- 답표현하기 조건: ① 서술 형식(구간 측정) · ② 분량(엔진 답표지) · ③ 결론(구간 측정) · ④ 완결(엔진 답표지).
- 구간 측정이 있으면 ①③ 조건은 엔진 값, 교사는 **고치기만**. 없으면 「교사」(판정불가).

### 7-2. 4역량 (처방전_규칙 9장, 오종래 2026-10-23 확정)
- 네 파트 = 네 역량(1:1): 근거대기 → **개념소화력** · 세우기 → **논리구성력** · 풀기(논리펼치기) → **연산수행력** · 답구하기(답표현하기) → **핵심인지력**.
- 4역량은 인간 사고의 기원 — 과목별 능력이 아니다. 연산수행력도 인문에서는 글쓰기 · 논리 전개의 정확성 (9-8, 과목 제한 해제 — 과목마다 다른 것은 비중뿐).
- 처방전 구술: 강점 먼저(O 역량 마디), X 역량은 「(역량명)이 아직 소화되지 않은 흔적이 있습니다」. 인문사회는 제시문 · 논지 · 논증 · 결론 꼴 (9-1).
- **인문 처방전 문구 (10-0-3 확정 · 추천안)**:
  - X 역량이 없을 때 인문 기본 처방 = 「다음 논제에서도 제시문의 핵심을 소화하고 → 자신의 논지를 세우고 → 근거를 들어 논증을 펼치고 → 논제가 묻는 결론에 닿는 순서로 쓰기」. 인문 구술에 「계산 · 식 · 풀이」 말이 나오면 서버 검사가 다시 쓰게 한다.
  - 선택·적용형 4축 구술의 개념소화력 마디 K = 학생이 고른 관점(「[가]의 관점」) — 급소(「[다]의 해석」)가 아니다.
- 삼킴/소화 (9-2) · 건강검진표 ● ◐ ○ (9-3) · 「왜」 구술 (9-4) · 게이트 안 C1 (9-5: 앞 역량 X → 바로 뒤 역량 ◐까지, 번지지 않음, 점수는 그대로) · 성장 궤적 회차 (9-6) · 성향 읽기 (9-7)는 원전 그대로.
