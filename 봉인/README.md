# 봉인 — 표지→색 매핑 값이 사는 곳 (2026-09-18)

**격리(`격리/`)와 다르다.**
- `격리/` = 원전이 아닌 문서를 **증거로 남기는** 곳. git에 올라간다.
- `봉인/` = 원전의 **값**이 사는 곳. **git에 올라가지 않는다.** (`.gitignore`)

여기 올라가는 것은 `README.md`와 `표지사전.template.json` 둘뿐이다. 값이 든 파일은 올라가지 않는다.

## 왜 파일로 빼는가

표지→색 매핑을 소스에 적으면 그게 곧 공개다. 지금 `src/fq/lexicon.ts`가 그 상태이며,
`BUILD_PLAN.md` §4 불변원칙 4("매트릭스·기호·논리스위치는 로컬만")를 어기고 있다.
값을 파일로 빼면 엔진은 **구조만** 갖고, 값은 로컬에 남는다.

## 채우는 법

```
cp 표지사전.template.json 표지사전.json     # 이 파일만 채운다. 템플릿은 그대로 둔다
```

`표지사전.json`은 `.gitignore`에 걸려 있어 커밋되지 않는다.
다른 경로에 두려면 `HMOS_SEALED_PATH=/어딘가/표지사전.json`으로 덮어쓴다.

## 칸 안내 — 어느 표의 어느 칸인가

원전은 `봉인/기술백서초안.hwp`다. (`5색사고유도등_…_연구논문.docx`는 원전이 아니다 → `격리/`)

| JSON 키 | 백서 | 무엇을 적나 |
|---|---|---|
| `switches[]` | **§4-1** 논리스위치 사전 | `id` 스위치 번호 · `kind` 표지의 종류 · `markers` 조사·어미 **묶음**(한 음절이 아니라 "~가 되도록"처럼 통째로) · `intent` 사유의 의지 · `color` 그 등 · `action` 디지털 행동 지침 |
| `lights[]` | **§4-2** 5색 사고 유도등 | 등마다 `markers` 조사 목록 · `role` 그 등의 역할 |
| `matrix[]` | **§4-5** 디지털 사유 매트릭스 | `code` · `name` · `triggers` 트리거 표지 · `color` · `logic` 연산 로직 · `layer` 연산 우선순위 계층 |
| `symbols[]` | **§4-5** 수학 기호 매핑 | `flow` 사고흐름 · `color` · `codes` 매트릭스 코드 · `symbol` 수학 기호 · `markers` 언어 조사 |
| `forms[]` | **§4-3** 문제 구조 | `id` · `colors` 색 조합 · `name`. **닫힌 목록이 아니다** — 백서는 "이 문제 구조와 **그 조합**"이라 적는다(BUILD_PLAN §6-3). 조합형도 한 줄로 적으면 된다 |
| `apply` | — | 표지를 문장에 적용하는 방식. `longestMatchFirst`(긴 표지 먼저 맞출 것인가) · `precedence`(길이로 안 갈리는 충돌의 순서). **이것도 값이다** — 코드가 정하지 않는다 |
| `pending[]` | — | 판정 대기 표지. `color`는 판정 전까지 `null` |

행 개수는 정해두지 않았다. 템플릿에는 모양을 보이려고 빈 행을 하나씩만 뒀다.
(표별 개수 자체가 문서마다 어긋나 있다 — BUILD_PLAN §6-9 판정 8번)

### `kind` — 경로 그래프에서 자리가 갈린다

| 값 | 경로 그래프에서 | 뜻 |
|---|---|---|
| `"조사·어미"` | **노드** | 실체를 끌고 나와 색을 켜는 자리 |
| `"연결어"` · `"부사"` | **간선** | 노드와 노드 사이의 관계 |
| `null` | 어느 쪽도 아님 | 미결로 보고된다. 코드가 대신 정하지 않는다 |

`apply.longestMatchFirst`도 채워야 표지 스캔이 돈다. 비어 있으면(`null`) 엔진은
"적용 규칙 미정"으로 멈춘다 — 짧은 표지가 긴 표지를 먼저 먹는 사고를 막기 위해서다.

## 비워 둔 것 — 급소(K) 선정 규칙

백서에 **"급소·무게중심·최수렴·회오리"는 한 번도 나오지 않는다.** 5색을 켜는 데까지가
원전이 적어 둔 전부다. 규칙이 없는데 칸을 만들면 그 칸이 규칙을 부르므로,
스키마에 급소 필드를 두지 않았다. 원전이 서면 그때 칸을 연다.
(`src/fq/sealed/schema.ts` 끝, BUILD_PLAN §6-9 판정 7번)

## 엔진이 이 파일을 쓰는 방식

```
src/fq/sealed/schema.ts   구조(어떤 칸이 필요한가)만 정의 — 값 없음
src/fq/sealed/index.ts    로더. 파일이 없으면 소리 내어 실패한다
src/fq/lexicon.ts         markerTable()이 위 로더를 부른다 (v2 진입점)
```

**기본값으로 때우지 않는다.** 봉인 파일이 없으면 엔진은 색을 추측하지 않고 멈춘다.
조용한 기본값은 옛 하드코딩을 되살리는 길이다(BUILD_PLAN §6-8).

`pending[]`에 `color: null`로 남은 표지는 `undecided()`가 그대로 들어 올린다.
엔진은 그 자리에서 색을 고르지 않고 **미결로 보고한다.**
