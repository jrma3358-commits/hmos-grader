# 면접 급소 추출 명세서
## HMOS 면접 출제 — 자소서·생기부·학습활동 급소 추출 원칙
*2026-10-19 · 오종래 확정 · 초안 (고도화 예정)*

---

## 1. 원칙
- 급소는 엔진이 기능표지(조사·어미)에서 읽어낸다
- 사람이 임의로 정하지 않는다
- 급소 없으면 질문 없다
- 추출된 급소는 면접 질문의 뿌리가 된다
- 고도화는 실제 자료를 넣어보며 발견 시 추가한다

---

## 2. 자소서 급소 추출

### 2-1. 읽는 방식
- 학생이 쓴 글 → 조사·어미 살아있음 → 5색 추출 가능
- 문항별로 분리하여 각각 급소 추출
- 문장 단위로 읽음

### 2-2. 5색 대응
| 색 | 기능표지 예 | 자소서에서 |
|---|---|---|
| B | ~을, ~를, ~이, ~가 | 탐구한 실체, 활동 대상 |
| C | ~일 때, ~하면서, ~하여 | 조건·상황·계기 |
| P | ~이고 ~이다 (배경) | 활동 배경·맥락 |
| D | ~라고 정의했다, ~임을 알았다 | 새로 깨달은 개념 |
| Q | ~했습니다, ~하고 싶습니다 | 결과·목표·지원동기 |

### 2-3. 급소 확정 원칙
- 급소 = Q에 접힌 B (무게중심)
- 반복 등장하는 B → 급소 후보 1순위
- 지원학과와 연결되는 B → 급소 후보 2순위

### 2-4. 예시
원문: "○○ 실험에서 변수를 통제하며 인과관계를 탐구했습니다."
B: ○○ 실험 / D: 변수 통제 / Q: 인과관계 탐구
급소: 인과관계 탐구
출처: 자소서 N번 문항

---

## 3. 생기부 세부특기사항 급소 추출

### 3-1. 읽는 방식
- 교사가 쓴 글 → 학생 활동·역량 기술
- 과목별로 분리하여 각각 급소 추출

### 3-2. 과목별 급소 특성
| 과목 | 급소 중심 | 기능표지 예 |
|---|---|---|
| 수학 | 논리·풀이 경로 | ~를 활용하여, ~임을 증명함 |
| 국어 | 감상·해석·논거 | ~라고 분석함, ~를 통해 |
| 과학 | 실험·탐구 과정 | ~를 설계하여, ~를 관찰함 |
| 사회 | 개념 적용·판단 | ~를 적용하여, ~라고 판단함 |
| 영어 | 표현·소통 역량 | ~를 발표함, ~로 설명함 |

### 3-3. 급소 확정 원칙
- 반복 등장하는 역량 → 급소 1순위
- 교사 강조 표현("탁월한", "주도적으로", "스스로") → 급소 2순위
- 지원학과 연결 역량 → 급소 3순위

### 3-4. 예시
원문: "○○ 개념을 활용하여 ○○ 문제를 스스로 해결함"
B: ○○ 개념 / C: 활용하여 / Q: 문제 해결
급소: 문제 해결 (어떤 개념으로)
출처: ○○과목 세부특기사항

---

## 4. 학습활동·수상·독서 급소 추출

### 4-1. 읽는 방식
- 짧은 텍스트 → 급소 하나
- 활동명·수상명·도서명이 B
- "그래서 무엇을 얻었나"가 Q

### 4-2. 급소 확정 원칙
- 단독으로는 급소 확정 안 함
- 자소서·생기부 급소와 겹칠 때 → 급소 강화
- 지원학과와 연결될 때 → 급소 후보

### 4-3. 예시
원문: "○○ 경시대회 은상 / ○○ 도서 탐구보고서 작성"
B: ○○ 경시대회·○○ 도서 / Q: 탐구보고서
급소: 탐구 역량
출처: 수상·독서활동

---

## 5. 지원대학·학과 정보 급소 추출

### 5-1. 읽는 방식
- 학과 인재상·모집요강
- "어떤 학생을 원하는가" → B
- "무엇을 할 수 있어야 하는가" → Q

### 5-2. 급소 확정 원칙
- 학과 급소 ↔ 학생 급소 대조
- 겹치는 것 → 면접 핵심 급소
- 안 겹치는 것 → 보완 질문 후보

---

## 6. 급소 통합 우선순위

자소서 급소 + 생기부 급소 + 학과 급소
→ 겹치는 것: 핵심 급소 (면접 1순위)
→ 자소서만: 경험 급소 (면접 2순위)
→ 생기부만: 역량 급소 (면접 3순위)
→ 학과만: 보완 급소 (면접 4순위)

---

## 7. 고도화 예정
- 실제 자소서·생기부 넣어보며 발견 추가
- 과목별 기능표지 세분화
- 학과별 급소 패턴 누적
- 성적 분위별 급소 가중치 조정
