# 논리 펼치기 명세서
## HMOS 인문 채점 3축 — 논리 펼치기 인식 원칙
*2026-10-19 · 오종래 확정*

## 1. 정의
논리 펼치기 = 수학 풀기의 인문 버전
수학: 식 → 연산 수행 → 다음 식
인문: 논제 요구 → 제시문 근거 추출 → 논리 매듭 → 결론

## 2. 엔진이 읽는 기능표지

결론 연결:
따라서·그러므로·이를 통해·이로써·결국·종합하면·이처럼

근거 제시:
왜냐하면·이는·즉·다시 말해·구체적으로

대비·반론:
반면·그러나·하지만·이에 반해·반대로

수렴:
이처럼·결국·종합하면·이상에서·따라서

## 3. 도달 조건
다음 셋을 모두 충족해야 논리 펼치기 도달:
① 논제가 요구하는 근거를 제시문에서 실제로 추출
② 기능표지(결론연결·근거제시·대비·수렴)가 있음
③ 근거에서 결론으로 매듭이 이어짐

## 4. 다경로 인정
- 다른 제시문 근거로 같은 결론 → 인정
- 다른 논리 경로로 같은 매듭 → 인정
- 결론만 있고 경로 없음 → 불인정
- 근거 없이 주장만 → 불인정

## 5. 미도달 사례
- "따라서 ○○이다" (근거 없이 결론만)
- 제시문 인용만 하고 매듭 없음
- 논제 요구와 무관한 근거 사용
