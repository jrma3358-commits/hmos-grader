두 파일입니다. hmos screen a와 hmos screen b입니다.

화면 A 흐름:
로그인 → 문항 입력 → 분석 실행(2초 시뮬레이션) → 인식 결과(5색·급소·출제의도) → 완성도 확인 → 교사 확정 버튼 → 화면 B가 새 탭으로 열립니다.

화면 B 구조:
왼쪽에 확정 문항(급소·출제의도·원문)이 고정되고, 오른쪽에 루브릭·체크리스트·부분점수·모범답안이 펼쳐집니다. 루브릭·체크리스트·부분점수는 수정 버튼 클릭 시 인라인 편집, 모범답안은 오른쪽 사이드 패널로 편집됩니다.

지금은 샘플 데이터로 동작합니다. 실제 엔진(run.ts) 연결은 서버 구조가 잡히면 API 호출로 교체하면 됩니다.

보시고 수정할 부분 말씀해 주세요.

① Express 서버 (server.ts)
   화면에서 문항 받아 → run.ts 엔진 호출 → 결과 반환
