## 0. 이 문서의 자리
「왜」(정의 문서) 위에 선다. 모든 계산·비교는 「미소가 자라게 하기 위해」라는 방향 아래에서.
지수는 재기 위함이 아니라, 정확히 봐서 돕기 위함이다.

---

## 1. HMOS 학습수행역량 — 4개 (네 파트 = 네 역량)
채점의 네 파트(①②③④)가 곧 네 역량이다. 채점하면 역량이 저절로 나온다.
이름은 학생·부모가 바로 알아듣는 쉬운 말로.

| 역량 | 파트 | 무엇을 보나 | 측정 근거 |
|------|------|-------------|-----------|
| **개념소화력** | ① 근거대기 | 개념·정의를 삼켰나 소화했나 | B·D 조각 O/X + 부분점수 패턴 |
| **논리구성력** | ② 세우기 | 조건·논지를 세우는 힘 | C·P 조각 O/X |
| **연산수행력** | ③ 풀기 | 계산·논증이 정확한가 | 풀기 조각 O/X |
| **핵심인지력** | ④ 답구하기 | 급소에 눈길 주고 닿나 | K·Q 도달 |

- ⑤ 표현/논리성은 채점에서 소거함(재현성 편차 큼) → 역량도 4개.
- **한 역량은 한 파트(색)에서만 나온다 — 중복 없이 1:1(배타).** 채점의 조각 분해가 곧 역량.
- 이름 근거: 「개념소화력」에 「삼킴/소화」가 담김(정의의 핵심).
- 「핵심인지력」이 「왜」의 중심(급소를 보는 힘)과 직결.

## 2. 측정 계산 — 비중 먼저, 그다음 강약
별도 작업 없음. 채점(조각 분해·배점·정오)이 그대로 역량 지수가 된다.
= 「질문 인식에서 바로 서는 기둥」의 실현.
**핵심: 100 정규화 「전에」 과목별 역량 비중을 따로 계산한다.** 그래야 「과목 vs 역량」이 갈린다.

### 2-1. 과목별 「역량 비중」 (과목 고유 — 시험지에서)
```
그 과목 시험지의 모든 조각을 ①②③④로 분류 → 배점 합 → 비율
  수학:  ①20% ②30% ③40% ④10%   (연산 비중 큼)
  국어:  ①30% ②20% ③0%  ④50%   (핵심 비중 큼)
  영어:  ①40% ②20% ③0%  ④40%
```
- 비중 = 「이 과목이 어느 역량을 얼마나 요구하나」. 학생과 무관, 과목(시험지) 고유.
- 시험지마다 다를 수 있음 → 「이 시험지 비중」인지 「과목 일반 비중」인지 구분.
  여러 시험 쌓이면 「이 과목은 대체로 이 비중」이 나옴.

### 2-2. 학생 「역량 강약」 (학생 고유 — 전 과목 종합, 과목 무관)
```
학생이 맞춘 역량 조각 / 그 역량 조각 전체 → 역량별 강약
  예) ① 개념소화 78 · ② 논리구성 82 · ③ 연산수행 55 · ④ 핵심인지 90
  = 이 학생 고유의 역량 강약 (어느 역량이 강/약한가)
```

### 2-3. 비중 × 강약 = 과목별 성취 (왜 이 과목 되고 저 과목 안 되나)
```
과목별 역량 비중  ×  학생 역량 강약  =  과목별 성취 설명

예) 학생: ③연산수행 약함(55) · ④핵심인지 강함(90)
  수학(③비중40% 큼) × 연산약함 → 수학이 크게 무너짐
  국어(④비중50% 큼) × 핵심강함 → 국어를 잘함
  = 「같은 학생인데 수학 못하고 국어 잘함」이
     「약한 역량이 수학 비중 큼 × 강한 역량이 국어 비중 큼」으로 설명됨
```
- **두 층으로 나뉜다**: 역량 강약(학생 고유) × 과목 비중(과목 고유) = 과목별 발현.
- 이것이 정의의 「수학은 헤매는데 국어는 뛰어나다」를 곱셈으로 정확히 옮긴 것.
- (표시용으로 각 역량을 100 척도로 환산하되, 비중을 지운 채 비교하지 않는다.)

## 3. 과목별 산출 + 같은 역량 비교 — 진단
### 3-1. 과목별 산출 (있는 역량만)
```
수학:  ①72 ②88 ③55 ④90
국어:  ①85 ②80 ③--  ④92
영어:  ①78 ②75 ③--  ④70
사회:  ①90 ②85 ③--  ④88
```
- 과목에 없는 역량은 비워둠(연산은 수학·과학에만).

### 3-2. 같은 역량을 과목 가로질러 비교
```
①개념소화력: 수72 국85 영78 사90
②논리구성력: 수88 국80 영75 사85
③연산수행력: 수55            (수학·과학끼리만)
④핵심인지력: 수90 국92 영70 사88
```

### 3-3. 비교가 「왜」를 가른다 — 과목 문제 vs 역량 문제
- **한 과목만 낮음** = 그 과목의 문제.
  예) ④핵심 수90 국92 사88 인데 영70 → 「급소 보는 힘은 있으나 영어에서만」
     = 영어 자체(단어·독해) 문제이지, 핵심인지력 부족이 아님.
- **전 과목 낮음** = 그 역량 자체의 문제.
  예) ③연산 전반 낮음 → 연산력 자체를 다질 곳.
- **전 과목 높음** = 타고난 강점.
  예) ④핵심 전 과목 높음 → 강점(먼저 비출 것).
- 한 과목만 보면 「영어를 못한다」로 끝나지만, 비교하면 「영어의 핵심인지만 낮다」로 정밀해짐.
- 이것이 정의의 「수학은 헤매는데 국어는 뛰어나다」를 진단하는 방법.


### 3-4. 비교의 주의
- **없는 역량은 제외** (연산은 수학·과학끼리).
- **같은 이름도 과목마다 결이 있다** — ④핵심이 수학=급소잡기, 국어=주제파악, 영어=요지찾기.
  → 「정밀한 동일 척도」로 과신하지 말고 **「경향」으로** 읽는다. (겉핥기 금지)

---

### 3-5. 과목 묶음 — 역량 공유로 묶인다
과목이 묶이는 것은 「공유하는 역량」 때문이다.
```
수학·과학       = 논리구성 + 연산수행 (구조·정확)   → 이과 묶음
국어·영어·윤리  = 개념소화 + 핵심인지 (이해·통찰)   → 문과 묶음
```
- **묶음이 「기대선」**: 묶음에서 벗어난 과목 = 특이 신호.
  예) 문과 묶음 국92 윤88 인데 영70 → 영어만 유독(영어 특정 문제).
- **묶음의 강약 = 성향**: 이과 묶음 강 = 구조·정확형 / 문과 묶음 강 = 이해·통찰형.
  → 「성향 읽기」의 열쇠(4역량 개별보다 묶음으로 보면 경향이 자연스럽게 읽힘).
- **주의**: 묶음은 경향이지 법칙 아님(수학 잘해도 과학 약한 예외 있음 — 예외가 진단 포인트).
  가둠 아닌 성장(이과형이니 문과 포기 X). 근거는 역량(왜 묶이는지 자취로).


## 4. 삼킴 / 소화 — 전 과목을 놓고 본다 (정의의 심장)
「삼켰나 소화했나」는 별도 패턴 측정이 아니라 **전 과목을 놓고 비교**하면 나온다.
같은 논리를 **네 역량 모두**에 같은 방식으로 적용한다 — 그래야 입체적으로 진단된다.

### 판정 (역량이 낮게 나올 때, 전 과목을 펼쳐본다)
```
어느 역량이 낮음 → 전 과목을 놓고 본다:
  · 전 과목 고루 낮음 → 성향 문제 (그 역량 자체가 약함)
       특히 ①개념소화가 전 과목 낮음 = 「급히 삼키는 성향」(어디서든 대충 넘어감)
  · 한 과목만 낮음   → 그 과목의 벽 (그 과목 자체가 어려움, 삼킴 아님)
```
예)
```
①개념소화력:
  삼킴형  수55 국58 영52 사56  → 전 과목 낮음 = 급히 삼키는 성향
  수학벽  수55 국85 영82 사88  → 수학만 낮음 = 수학 자체가 벽(삼킴 아님)
```
- 수학만 놓고 보면 둘 다 「55」로 같다. **전 과목 펼쳐야 원인이 갈린다.**
- 이는 3-3(과목 vs 역량)과 같은 논리 — 삼킴/소화도 그 한 경우다.

### 처방이 정반대로 갈린다 (정의의 목적)
- **삼킴형** → 「전반적으로 급히 넘어가는 성향. 하나를 끝까지 소화하는 습관을」 (성향 코칭)
- **과목벽형** → 「다른 건 소화 잘하는데 그 과목만 벽. 그 과목 기초를」 (과목 처방)
- 같은 「개념소화 약함」인데 처방이 반대 — 전 과목 놓고 봐야 맞는 처방이 나온다.
- 이것이 정의의 두 아이(급히 삼켜 다 무너짐 / 한 과목만 못함)를 정확히 구분하는 법.

## 5. 입체 진단 + 출력 (건강검진표처럼)

### 5-1. 입체 진단 — 4역량 × 과목 격자
네 역량을 모두 전 과목 놓고 보면, 학습수행능력이 「평면(한 점수)」이 아니라 「입체」로 드러난다.
- 세로 = 4역량(개념소화·논리구성·연산수행·핵심인지)
- 가로 = 과목(수학·국어·영어·사회·과학)
- 격자 전체 = 「어느 역량이 어느 과목에서」 강하고 막혔는가 = 실체적·입체적 진단.

### 5-2. 출력 — 건강검진표형
건강검진표처럼 낸다. 재는 것이 아니라 「상태를 보여주고 관리법을 주는」 형식.
```
┌─────────────────────────────────────┐
│  ○○○ 학습수행역량 진단표             │
├─────────────────────────────────────┤
│         수학 국어 영어 사회 과학      │
│ 개념소화  ●   ●   ○   ●   ●        │
│ 논리구성  ●   ●   ○   ●   ◐        │
│ 연산수행  ◐   -   -   -   ◐        │
│ 핵심인지  ●   ●   ◐   ●   ●        │
│   (● 강점 · ◐ 보통 · ○ 다질 곳)     │
├─────────────────────────────────────┤
│ [종합 소견]                          │
│  강점 먼저 → 다질 곳 → 성향          │
├─────────────────────────────────────┤
│ [성장 안내 — 네비게이션]             │
│  "핵심 보는 힘이 강하니, 영어 기초    │
│   개념을 다지면 전반이 오릅니다."     │
└─────────────────────────────────────┘
```
- 건강검진표가 좋은 모델인 이유: 재지 않고 상태를 보여줌 / 강점·약점 나란히 /
  종합 소견 + 관리 안내 / 부모·학생·선생 모두 익숙(세 사람의 눈).
- **상태 표시** = 숫자 아닌 기호(●◐○)나 말(강함/보통/다질 곳). 숫자(72)는 내부 계측용.
  → 오늘 「내부 숫자 / 외부 서술」·낙인 방지 그대로.
- **종합·안내** = 강점 먼저 · 약점은 성장으로 · 미래는 열린 가능성으로.
  삼킴/소화 진단(4장)을 소견에 담는다(「급히 삼키는 성향」 vs 「그 과목 벽」).

## 6. 게이트 — 순차 종속 (수리 문항)
- 봉인④-b 게이트: 앞 파트 X면 뒤 상한.
- 역량 지수에도 반영: 「①개념 무너졌는데 ④핵심만 높게」는 이상(개념 없이 급소 도달 불가).
- 순차 종속 문항에서 게이트가 역량 계산에 어떻게 걸리는지 확정 필요(6장).

## 7. 아직 정할 것 (다음)
- [x] **삼킴/소화** — 전 과목 놓고 판정, 네 역량 공통 (4장 반영).
- [ ] **게이트 반영** — 순차 종속을 역량 지수에 어떻게(5장).
- [x] **중복 제거(확정)** — 한 역량은 한 파트·색에서만 나온다(1:1). 여러 색 걸침 없음.
      개념소화=①(B·D) / 논리구성=②(C·P) / 연산수행=③ / 핵심인지=④(K·Q). 깔끔하게 배타.
- [~] **성향 읽기** — 과목 묶음(이과/문과)의 강약이 열쇠(3-5). 4역량 조합 → 경향. 고정 딱지 아닌 현재 경향.
- [x] **출력** — 건강검진표형, 입체 진단(4역량×과목), 상태 기호·서술 (5장 반영).
- [ ] **성장 궤적** — 시간축(측정 쌓이면 궤적). 필요할 때 추적, 필요한 사람이 봄.
- [x] **미래 직업군 삭제(확정)** — 초·중·고1·2에 낯선 외투이므로 넣지 않는다.
      역량·성향의 강점까지만 본다. MCP 연동 불필요(3단계 내부 완결). 직업 연결은 두지 않음.

## 8. 접목 — 30년 + AI
- **30년(오종래)**: 무엇이 바른 역량인가, 어느 조각이 어느 역량인가, 삼킴/소화의 눈.
- **AI**: 정오답을 조각·색·파트로 분석·집계, 100 정규화, 과목 비교 — 연산·패턴 분석.
- **못/안 하는 것**: 필체 등 「논리 아닌 물리 흔적」은 근거 약해 무리하지 않음(사람 몫).
  = 오늘 「출처 버리기」와 같은 절제.
